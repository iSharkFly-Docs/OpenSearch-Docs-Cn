# Ingest APIs
<Badge type="tip" text="Introduced 1.0" />

Ingest APIs are a valuable tool for loading data into a system. Ingest APIs work together with [ingest pipelines](/ingest-pipelines/) and [ingest processors](/ingest-pipelines/processors/index-processors) to process or transform data from a variety of sources and in a variety of formats. 

## Ingest pipeline APIs

Simplify, secure, and scale your OpenSearch data ingestion with the following APIs:

- [Create pipeline](/ingest-pipelines/create-ingest): Use this API to create or update a pipeline configuration.
- [Get pipeline](/ingest-pipelines/get-ingest): Use this API to retrieve a pipeline configuration.
- [Simulate pipeline](/ingest-pipelines/simulate-ingest): Use this pipeline to test a pipeline configuration.
- [Delete pipeline](/ingest-pipelines/delete-ingest): Use this API to delete a pipeline configuration.
