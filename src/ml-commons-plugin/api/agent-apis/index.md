# Agent APIs
<Badge type="tip" text="Introduced 2.12" />

::: danger WARNING
This is an experimental feature and is not recommended for use in a production environment. For updates on the progress of the feature or if you want to leave feedback, see the associated [GitHub issue](https://github.com/opensearch-project/ml-commons/issues/1161).    
:::

You can automate machine learning (ML) tasks using agents and tools. An _agent_ orchestrates and runs ML models and tools. For more information, see [Agents and tools](/ml-commons-plugin/agents-tools/).

ML Commons supports the following agent-level APIs:

- [Register agent](/ml-commons-plugin/api/agent-apis/register-agent)
- [Execute agent](/ml-commons-plugin/api/agent-apis/execute-agent)
- [Get agent](/ml-commons-plugin/api/agent-apis/get-agent)
- [Search agent](/ml-commons-plugin/api/agent-apis/search-agent)
- [Delete agent](/ml-commons-plugin/api/agent-apis/delete-agent)
