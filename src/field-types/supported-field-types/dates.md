# Date field types

Date field types contain a date value that can be formatted using different date formats. The following table lists all date field types that OpenSearch supports. 

Field data type | Description
:--- | :---  
[`date`](/field-types/supported-field-types/date) | A date stored in millisecond resolution.
[`date_nanos`](/field-types/supported-field-types/date-nanos) | A date stored in nanosecond resolution.
