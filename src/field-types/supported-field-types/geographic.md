# Geographic field types

Geographic fields contain values that represent points or shapes on a map. The following table lists all geographic field types that OpenSearch supports.

Field data type | Description
:--- | :---  
[`geo_point`](/field-types/supported-field-types/geo-point) | A geographic point specified by latitude and longitude. 
[`geo_shape`](/field-types/supported-field-types/geo-shape) | A geographic shape, such as a polygon or a collection of geographic points.
