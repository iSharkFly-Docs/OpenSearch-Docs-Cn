# Workflow APIs

::: danger WARNING
This is an experimental feature and is not recommended for use in a production environment. For updates on the progress of the feature or if you want to leave feedback, see the associated [GitHub issue](https://github.com/opensearch-project/flow-framework/issues/475).    
:::

OpenSearch supports the following workflow APIs:

* [Create or update workflow](/automating-configurations/api/create-workflow)
* [Get workflow](/automating-configurations/api/get-workflow)
* [Provision workflow](/automating-configurations/api/provision-workflow)
* [Get workflow status](/automating-configurations/api/get-workflow-status)
* [Get workflow steps](/automating-configurations/api/get-workflow-steps)
* [Search workflow](/automating-configurations/api/search-workflow)
* [Search workflow state](/automating-configurations/api/search-workflow-state)
* [Deprovision workflow](/automating-configurations/api/deprovision-workflow)
* [Delete workflow](/automating-configurations/api/delete-workflow)
