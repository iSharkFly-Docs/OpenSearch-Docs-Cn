# Mutate event processors

Mutate event processors allow you to modify events in Data Prepper. The following processors are available:

* [add_entries](/data-prepper/pipelines/configuration/processors/add-entries) allows you to add entries to an event.
* [copy_values](/data-prepper/pipelines/configuration/processors/copy-values) allows you to copy values within an event.
* [delete_entries](/data-prepper/pipelines/configuration/processors/delete-entries) allows you to delete entries from an event.
* [rename_keys](/data-prepper/pipelines/configuration/processors/rename-keys) allows you to rename keys in an event.
* [convert_entry_type](/data-prepper/pipelines/configuration/processors/convert_entry_type) allows you to convert value types in an event.
* [list_to_map](/data-prepper/pipelines/configuration/processors/list-to-map) allows you to convert list of objects from an event where each object contains a `key` field into a map of target keys.
