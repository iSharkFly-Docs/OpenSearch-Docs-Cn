# 对象字段类型

对象字段类型（Object Field Type）包含对象或关系类型的值。下表列出了 OpenSearch 支持的所有对象字段类型。

字段数据类型 | 描述
:--- | :---  
[`object`](/field-types/supported-field-types/object) | JSON 对象。 
[`nested`](/field-types/supported-field-types/nested) | 当数组中的对象需要作为单独的文档独立索引时使用。 
[`flat_object`](/field-types/supported-field-types/flat-object) | 被视为字符串的 JSON 对象。
[`join`](/field-types/supported-field-types/join) | 在同一索引中的文档之间建立父子关系。
