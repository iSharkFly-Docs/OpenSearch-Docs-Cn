# 跨度查询

你可以使用跨度查询（Span Query）执行精确的位置搜索。跨度查询是底层的特定查询，可以控制指定查询词项的顺序和邻近程度。它们主要用于搜索法律文档和专利。 

跨度查询包括以下查询类型：

- **Span containing**：包装一组跨度查询，只返回与第二个跨度查询匹配的跨度。 
- **Span field masking**：在不同字段之间组合 `span_near` 或 `span_or`。
- **Span first**：匹配靠近字段开头的跨度。
- **Span multi-term**：为以下查询类型提供包装：`term`、`range`、`prefix`、`wildcard`、`regexp` 或 `fuzzy`。
- **Span near**：匹配彼此靠近的跨度。包装多个跨度查询，这些查询必须在彼此指定的 `slop` 距离内匹配，并可选择要求按相同顺序匹配。Slop 表示中间未匹配位置的最大数量，并指示是否要求按顺序返回匹配项。
- **Span not**：为另一个跨度查询提供包装，并排除与内部查询匹配的所有文档。
- **Span or**：为多个跨度查询提供包装，并包含与任一指定查询匹配的所有文档。
- **Span term**：作用与 `term` 查询相同，但专门设计用于与其他跨度查询配合使用。
- **Span within**：与其他跨度查询配合使用，如果某个跨度查询的跨度位于一组其他跨度查询返回的跨度之内，则返回该跨度查询。
