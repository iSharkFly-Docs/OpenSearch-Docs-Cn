# JDBC 驱动程序

Java 数据库连接（Java Database Connectivity，JDBC）驱动程序可以让你将 OpenSearch 与常用的商业智能（BI）应用程序集成。

关于下载和使用 JAR 文件的信息，请参阅 [GitHub 上的 SQL 仓库](https://github.com/opensearch-project/sql-jdbc)。

## 连接 Tableau

要连接 Tableau，请按照 [GitHub 仓库](https://github.com/opensearch-project/sql-jdbc/blob/main/bi-connectors/TableauConnector/README.md)中的详细说明操作。
