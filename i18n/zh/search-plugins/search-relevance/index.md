# 搜索相关性

搜索相关性（search relevance）用于评估查询返回的搜索结果的准确程度。相关性越高，搜索引擎就越好。 

OpenSearch 提供以下搜索相关性功能：

- 在 OpenSearch Dashboards 中并排[比较两个查询的搜索结果](/search-plugins/search-relevance/compare-search-results)。 

- 使用交叉编码器（cross-encoder）重排序器[对搜索结果进行重排序](/search-plugins/search-relevance/reranking-search-results)。 

- 使用 [Querqy](/search-plugins/querqy/) 改写查询。
