# 安装和升级 OpenSearch

OpenSearch 和 OpenSearch Dashboards 可以在任何支持 Docker 的兼容主机（例如 Linux、MacOS 或 Windows）上运行。此外，你还可以在多种 Linux 发行版和 Windows 上安装这两个产品。

针对你的平台[下载 OpenSearch](https://opensearch.org/downloads.html)，然后选择以下任一安装指南。

| OpenSearch | OpenSearch Dashboards |
| :--- | :--- |
| [Docker](/install-and-configure/install-opensearch/docker) | [Docker](/install-and-configure/install-dashboards/docker) |
| [Helm](/install-and-configure/install-opensearch/helm) | [Helm](/install-and-configure/install-dashboards/helm) |
| [Tarball](/install-and-configure/install-opensearch/tar) | [Tarball](/install-and-configure/install-dashboards/tar) |
| [RPM](/install-and-configure/install-opensearch/rpm) | [RPM](/install-and-configure/install-dashboards/rpm) |
| [Debian](/install-and-configure/install-opensearch/debian) | [Debian](/install-and-configure/install-dashboards/debian) |
| [Ansible playbook](/install-and-configure/install-opensearch/ansible) | |
| [Windows](/install-and-configure/install-opensearch/windows) | [Windows](/install-and-configure/install-dashboards/windows) |

安装 OpenSearch 后，请了解如何针对你的部署[配置](/install-and-configure/configuring-opensearch/) OpenSearch。

有关升级 OpenSearch 集群（Cluster）的更多信息，请参阅[升级指南](/install-and-configure/upgrade-opensearch/)。

有关升级工具的信息，请参阅 [OpenSearch 升级、迁移和比较工具](/tools/#opensearch-upgrade-migration-and-comparison-tools)。

有关插件安装，请参阅[安装插件](/install-and-configure/plugins)。
