# 升级附录

升级附录提供更多辅助文档，例如包含示例 API 请求和配置文件的实验，用于补充相关的流程文档。附录中列出的具体步骤可以有多种用法：

- OpenSearch 新用户可以借助我们提供的步骤和示例资源，学习如何配置和使用 OpenSearch 及 OpenSearch Dashboards。
- 管理 OpenSearch 集群的系统管理员可以使用我们提供的示例，先在测试环境中模拟集群维护，再将变更应用到生产工作负载。

如果你希望我们补充某个特定主题，请在 GitHub 上 [OpenSearch Project](https://github.com/opensearch-project) 的 issue [#2830](https://github.com/opensearch-project/documentation-website/issues/2830) 下留言。

::: info 注意
本附录中的具体命令只是与 OpenSearch API 及底层主机交互的示例，用于演示相关升级流程文档中描述的步骤。其目的并非给出严格的规定，而是为刚接触 OpenSearch、希望看到实际示例的用户提供更多背景信息。
:::
